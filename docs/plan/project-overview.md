# Project Overview

## Goal

Create gazebo terrain using mesh like dae files

## Runtime Constraint

This is a standalone Gazebo project.

Do not use:

- ROS or ROS 2
- `ros2 launch`
- ROS launch files
- colcon workspaces
- ROS packages
- ROS environment variables

Use:

- Gazebo CLI, especially `gz sim`
- Gazebo SDF worlds and models
- Shell or Python scripts for startup
- `GZ_SIM_RESOURCE_PATH` for model lookup
